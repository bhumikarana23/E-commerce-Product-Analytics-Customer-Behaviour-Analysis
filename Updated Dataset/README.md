# Cleaned E-Commerce Datasets

## Overview

This folder contains the cleaned and processed Excel datasets prepared for the **E-Commerce Product Analytics & Customer Behaviour Analysis** project.

The datasets were organised and cleaned using Microsoft Excel to improve data consistency, readability, and usability for further analysis.

These workbooks serve as the prepared data source for subsequent analytical tasks involving customer behaviour, product performance, transaction trends, and e-commerce business metrics.

## Cleaned Dataset Files

The folder contains the following cleaned Excel workbooks:

| File | Description |
|---|---|
| customers_cleaned.xlsx | Cleaned customer information and signup details |
| products_cleaned.xlsx | Cleaned product catalogue and attributes |
| events_cleaned.xlsx | Cleaned customer browsing and shopping interactions |
| orders_cleaned.xlsx | Cleaned order and transaction information |
| order_items_cleaned.xlsx | Cleaned individual order-item records |

## Data Preparation

The cleaning and preparation process was carried out using Microsoft Excel, focusing on:

- Reviewing dataset structure and column consistency.
- Checking for missing and inconsistent values.
- Standardising data formats where required.
- Improving data readability and organisation.
- Preparing structured workbooks for further analysis.

## Analytical Applications

The cleaned datasets can be used for:

1. Customer behaviour and purchasing pattern analysis.
2. Product and category performance evaluation.
3. E-commerce conversion funnel analysis.
4. Shopping cart and checkout abandonment analysis.
5. Order and revenue analysis.
6. Customer segmentation and retention analysis.
7. Business intelligence reporting and dashboard development.

## Tools Used

- Microsoft Excel
- Python
- Pandas
- MySQL
- Power BI

## File Format

All datasets are provided in Microsoft Excel workbook format (`.xlsx`).

## Disclaimer

These datasets contain synthetic information generated exclusively for educational, analytical, and portfolio development purposes.

They do not represent actual customer records, transactions, or proprietary data from Myntra or any other e-commerce company.
